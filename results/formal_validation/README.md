# CIFAR-10 正式验证与测试总结

## 方法

CIFAR-10 官方训练集先按类别分层划出 5,000 张验证图片，其余 45,000 张构成训练候选池。`train.py` 每轮只使用训练集更新参数、使用验证集选择 checkpoint；候选配置确定前不查看官方测试指标。固定配置完成后，`evaluate.py` 才在 10,000 张官方测试图片上执行最终评估。

旧的 `results/experiments.csv` 来自测试集参与逐轮选模的探索性流程，只保留为学习历史；本总结只使用 `formal_validation_experiments.csv` 与 `formal_test_results.csv` 中的正式复验结果。

## 25% 数据候选配置

| 数据增强 | Dropout | 最佳轮次 | 验证准确率 | 验证损失 |
| --- | ---: | ---: | ---: | ---: |
| none | 0.0 | 8 | 60.78% | 1.2344 |
| basic | 0.0 | 10 | 59.70% | 1.1734 |
| none | 0.3 | 8 | **61.66%** | **1.1277** |
| basic | 0.3 | 8 | 57.72% | 1.1681 |

验证集选择 `augmentation=none`、`Dropout=0.3`、`weight_decay=0`。该配置的最终测试损失为 1.1086，测试准确率为 62.58%。详细结果见 [25% 数据实验总结](25pct/README.md)。

## 100% 数据正式对照

固定模型、10 个 epoch、batch size 64、SGD、学习率 0.1、`augmentation=none` 和 `weight_decay=0`，使用随机种子 42、123、999 进行配对复验，只改变 Dropout：

| 种子 | 无 Dropout 测试准确率 | Dropout=0.3 测试准确率 | 配对提升 |
| ---: | ---: | ---: | ---: |
| 42 | 70.54% | 72.82% | +2.28 个百分点 |
| 123 | 66.73% | 70.47% | +3.74 个百分点 |
| 999 | 69.05% | 72.24% | +3.19 个百分点 |
| 均值 ± 样本标准差 | 68.77% ± 1.92% | **71.84% ± 1.22%** | **+3.07 ± 0.74 个百分点** |

三个种子下 `Dropout=0.3` 的测试准确率均高于配对基线。在当前 SimpleCNN、训练预算和超参数设置下，这为适度 Dropout 的正向作用提供了比单次运行更稳定的证据；三次复验仍不足以支持“普遍最优”或统计显著性的结论。

逐种子测试损失和原始记录见 `results/formal_test_results.csv`，统计可由项目根目录的 `analyze_formal_multiseed.py` 自动复算。

## 跨数据规模观察

以种子 123 为例，同一 `Dropout=0.3` 配置从 25% 训练池扩展至 100% 后，训练样本从 11,250 增至 45,000，验证准确率从 61.66% 提升至 70.40%，测试准确率从 62.58% 提升至 70.47%，测试准确率增加 7.89 个百分点。

当前结论仅适用于固定模型、训练预算和三个随机种子。种子 123 的 100% 无 Dropout 基线在第 5 轮后验证指标明显波动，说明固定学习率下后期训练不稳定；最佳 checkpoint 机制避免了更差的后续轮次覆盖已有最优模型。后续若研究学习率或调度器，需要重新以验证集选择方案，不能根据本次测试结果继续调参。
