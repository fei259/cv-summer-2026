# CIFAR-10 正式验证与测试总结

## 方法

CIFAR-10 官方训练集先按类别分层划出 5,000 张验证图片，其余 45,000 张构成训练候选池。`train.py` 每轮只使用训练集更新参数、使用验证集选择 checkpoint；候选配置确定前不查看官方测试指标。固定配置完成后，`evaluate.py` 才在 10,000 张官方测试图片上执行最终评估。

旧的 `results/experiments.csv` 来自测试集参与逐轮选模的探索性流程，只保留为学习历史；本总结只使用 `formal_validation_experiments.csv` 与 `formal_test_results.csv` 中的正式复验结果。

## 25% 数据候选配置

| 数据增强 | Dropout | 最佳轮次 | 验证准确率 | 验证损失 |
| --- | ---: | ---: | ---: | ---: |
| none | 0.0 | 8 | 60.78% | 1.2344 |
| basic | 0.0 | 10 | 59.70% | 1.1734 |
| none | 0.3 | 8 | **61.66%** | **1.1277** |
| basic | 0.3 | 8 | 57.72% | 1.1681 |

验证集选择 `augmentation=none`、`Dropout=0.3`、`weight_decay=0`。该配置的最终测试损失为 1.1086，测试准确率为 62.58%。详细结果见 [25% 数据实验总结](25pct/README.md)。

## 100% 数据正式对照

固定模型、数据划分、10 个 epoch、batch size 64、SGD、学习率 0.1、`weight_decay=0` 和随机种子 123，只改变 Dropout：

| Dropout | 最佳轮次 | 训练准确率 | 验证准确率 | 测试准确率 | 测试损失 | 训练－测试差距 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.0 | 5 | 79.68% | 67.08% | 66.73% | 1.0411 | 12.95% |
| 0.3 | 9 | 83.59% | **70.40%** | **70.47%** | **1.0119** | 13.12% |

`Dropout=0.3` 相较基线将验证准确率提高 3.32 个百分点、测试准确率提高 3.74 个百分点，并将测试损失降低 0.0292。验证与测试得到同方向结果，且 Dropout 配置的两者只差 0.07 个百分点。

训练－测试差距用于辅助观察拟合程度，不能单独决定模型优劣。`13.12%` 是 Dropout 模型自身的差距，不是它相对基线的准确率收益；本次主要结论来自更高的验证/测试准确率和更低的测试损失。

## 跨数据规模观察

同一 `Dropout=0.3` 配置从 25% 训练池扩展至 100% 后，训练样本从 11,250 增至 45,000，验证准确率从 61.66% 提升至 70.40%，测试准确率从 62.58% 提升至 70.47%，测试准确率增加 7.89 个百分点。

当前结论仅适用于固定模型、训练预算和单个随机种子。100% 无 Dropout 基线在第 5 轮后验证指标明显波动，说明固定学习率下后期训练不稳定；最佳 checkpoint 机制避免了更差的后续轮次覆盖已有最优模型。后续若研究学习率或调度器，需要重新以验证集选择方案，不能根据本次测试结果继续调参。
