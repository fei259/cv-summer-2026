# 最终模型错误分析

## 实验配置

- 模型：SimpleCNN
- 训练集 / 验证集：45,000 / 5,000
- 数据增强：none
- Dropout：0.3
- Weight Decay：0.0
- 由验证集选择最佳轮次：epoch 9
- 最终测试集准确率：70.47%

## 主要错分现象

| 真实类别 | 最常预测为 | 数量 | 可能原因 |
| --- | --- | ---: | --- |
| bird | deer | 193 | 低分辨率下鸟的局部特征不清晰，绿色自然背景可能造成干扰。 |
| dog | cat | 158 | 同属宠物动物，姿态、毛色和局部轮廓相近。 |
| cat | dog | 155 | 与 dog → cat 一起反映细粒度动物类别难区分。 |
| frog | deer | 148 | 自然背景与模糊轮廓可能使模型偏向其他动物类别。 |
| horse | deer | 120 | 四足动物轮廓、毛色和场景相近。 |
| automobile | truck | 79 | 都具有车辆车身与车轮等共有结构。 |
| truck | automobile | 79 | 与 automobile → truck 构成双向混淆。 |
| ship | airplane | 74 | 远景下的长条轮廓与蓝灰背景容易混淆。 |
| airplane | ship | 57 | 与 ship → airplane 构成双向混淆。 |

## 结论

模型已能学习到主要类别特征，但对低分辨率下的细粒度动物、相似交通工具及背景干扰仍不够鲁棒。`typical_errors.png` 用于展示各真实类别最常见错分类型的一张示例图；混淆原因仍需结合整类样本的统计结果谨慎判断。
