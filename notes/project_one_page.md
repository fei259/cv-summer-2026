# CIFAR-10 图像分类受控实验项目

## 一句话介绍

基于 PyTorch 搭建两层卷积的 SimpleCNN，在 CIFAR-10 十分类任务上受控比较训练数据量、数据增强、Dropout 与 Weight Decay，并建立训练、验证选模、独立测试和错误分析相互分离的可复现实验流程。

## 问题与目标

- 研究训练数据量变化对图像分类性能的影响。
- 比较数据增强、Dropout 和 Weight Decay 在当前模型及训练预算下的作用。
- 检验有限数据阶段选出的配置扩展到完整训练池后是否仍然有效，并修正早期直接使用测试集选模的不规范流程。

## 方法与实验协议

- CIFAR-10 包含 50,000 张官方训练图片和 10,000 张测试图片。使用随机种子 123 按类别分层划分出 45,000 张训练图片和 5,000 张验证图片，测试集始终保留到配置锁定后使用。
- 模型由两层 `Conv2d + ReLU + MaxPool2d`、一个 128 维全连接隐藏层和可配置 Dropout 组成，最终输出十个类别的 logits。
- 固定 SGD、学习率 0.1、batch size 64 和 10 个 epoch，比较不同训练数据比例、数据增强及正则化配置。训练集负责参数更新，验证集负责选择最佳轮次与候选配置，测试集仅执行最终评估。
- 项目提供命令行训练、评估和单图预测入口，统一保存 checkpoint、CSV 指标、训练曲线、混淆矩阵和典型错分样本；已在全新 Python 3.12 CPU 环境中完成从依赖安装到单图推理的复现验证。

## 核心结果

- 在 11,250 张训练图片的正式候选实验中，`augmentation=none、Dropout=0.3、weight_decay=0` 获得最高验证准确率 61.66%，最终测试准确率为 62.58%。
- 将该配置扩展至 45,000 张训练图片后，验证准确率达到 70.40%，测试准确率达到 70.47%，较同规模无 Dropout 基线的 66.73% 提高 3.74 个百分点，测试损失由 1.0411 降至 1.0119。
- 相同 Dropout 配置从 11,250 张扩展到 45,000 张训练图片后，测试准确率提高 7.89 个百分点，说明增加训练数据对当前任务有明显帮助。

## 错误分析

混淆矩阵与典型错分样本表明，模型对 `ship`、`deer` 和 `automobile` 识别较好，主要困难集中在 `cat`、`bird`、`dog` 等细粒度动物，以及 `automobile↔truck`、`airplane↔ship` 等外观相近的交通工具。低分辨率、相似轮廓和背景干扰可能是重要原因，但样本展示只能提供解释线索，不能单独证明因果关系。

## 局限与下一步

当前实验只使用两层卷积的 SimpleCNN、单个正式随机种子、固定训练轮数和学习率；项目早期还曾多次查看测试集，因此现有结果应视为评价流程修正后的复验证据，而不是普遍最优结论。后续可增加多随机种子并报告均值与标准差，引入学习率调度和 ResNet 等更强模型，同时在新的任务中从一开始保留完全未见的测试集。
