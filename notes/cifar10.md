# CIFAR-10 数据集说明

## 基本信息

- 图片总数：60,000
- 训练集数量：50,000
- 测试集数量：10,000
- 类别数量：10
- 单张图片尺寸：32 × 32
- 图片类型：RGB 彩色图片

## 类别

标签 `0～9` 依次对应：

1. airplane
2. automobile
3. bird
4. cat
5. deer
6. dog
7. frog
8. horse
9. ship
10. truck

## Tensor 形状

- 单张图片：`(3, 32, 32)`
- 一个 batch 的图片：`(64, 3, 32, 32)`
- 一个 batch 的标签：`(64,)`
- 图片维度顺序：`通道 × 高度 × 宽度`

与 FashionMNIST 的主要区别：

- FashionMNIST：单通道灰度图，形状为 `(1, 28, 28)`。
- CIFAR-10：三通道彩色图，形状为 `(3, 32, 32)`。

## 数据预处理

1. `ToTensor()`：把 PIL 图片转换为 PyTorch Tensor，将像素从 `0～255` 缩放到 `0～1`，并把维度排列为 `(C, H, W)`。
2. `Normalize()`：根据 RGB 三个通道各自的均值和标准差进行标准化，使数据大致以 0 为中心。

使用的通道均值：

```python
CIFAR10_MEAN = (0.4914, 0.4822, 0.4465)
```

使用的通道标准差：

```python
CIFAR10_STD = (0.2470, 0.2435, 0.2616)
```

标准化与反标准化公式：

```text
标准化值 = (原值 - 均值) / 标准差
反标准化值 = 标准化值 × 标准差 + 均值
```

## DataLoader 设置

| 数据集 | batch_size | shuffle | num_workers |
|---|---:|---|---:|
| 训练集 | 64 | `True` | 0 |
| 测试集 | 64 | `False` | 0 |

训练集需要打乱，以避免模型受到固定样本顺序的影响。测试集评估结果与顺序无关，保持固定顺序更方便复现和排查问题。

## 评价指标

- 损失函数：交叉熵损失 `CrossEntropyLoss`，用于指导模型更新参数。
- 主要评价指标：分类准确率 `Accuracy`，用于直观衡量分类结果。

```text
准确率 = 预测正确的样本数 / 总样本数
```
