# Dropout 实验计划

## 实验目的

研究不同 Dropout 概率对 CIFAR-10 图像分类模型的训练表现、测试表现和泛化能力的影响。

## 第一阶段：单变量筛选

固定以下配置：

- 数据集：CIFAR-10
- 模型：SimpleCNN
- 训练数据比例：25%
- 数据增强：none
- 随机种子：123
- batch size：64
- epoch：10
- 优化器：SGD
- 学习率：0.1
- weight decay：0

只改变 `dropout_rate`：

| 实验组 | dropout_rate | 作用 |
|---|---:|---|
| 无 Dropout | 0.0 | 对照组 |
| 中等 Dropout | 0.3 | 观察适度正则化效果 |
| 较高 Dropout | 0.5 | 检查是否出现正则化过强 |

## 实验假设

- Dropout 增大后，训练准确率可能下降。
- 适度 Dropout 可能缓解过拟合，提高测试准确率。
- Dropout 过高可能导致欠拟合，使训练和测试准确率同时下降。

## 评价指标

主要比较：

1. 最佳测试准确率
2. 最佳测试损失
3. 对应轮次的训练准确率
4. 泛化差距

泛化差距：

`best_train_accuracy - best_test_accuracy`

不能只选择泛化差距最小的模型，因为欠拟合也可能造成很小的差距。应以测试准确率为主要指标，测试损失和泛化差距作为辅助指标。

## 后续验证

第一阶段选出较合适的 Dropout 概率后，再使用其他随机种子复验，避免根据单次训练的偶然结果下结论。
