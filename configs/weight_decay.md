# Weight Decay 实验计划

## 实验目的

研究不同权重衰减强度对 SimpleCNN 训练表现、测试表现和泛化能力的影响。

## 控制变量

- 数据集：CIFAR-10
- 训练数据比例：25%
- 数据增强：none
- Dropout：0.0
- 随机种子：123
- batch size：64
- epoch：10
- 优化器：SGD
- 学习率：0.1

## 自变量

| 实验组 | weight_decay |
| --- | ---: |
| 对照组 | 0.0 |
| 轻度权重衰减 | 0.0001 |
| 中等权重衰减 | 0.001 |

## 实验假设

- 适度的 Weight Decay 可能限制过大的模型权重，缓解过拟合。
- 正则化增强后，训练准确率可能下降。
- Weight Decay 过大可能造成欠拟合，使训练和测试准确率同时下降。

## 评价指标

主要比较最佳测试准确率，同时参考：

1. 最佳测试损失
2. 对应轮次的训练准确率
3. 泛化差距
4. 训练耗时

不能仅凭泛化差距选择模型，应以测试准确率为主要依据。
